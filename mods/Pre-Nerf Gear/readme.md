# Pre-Nerf Gear

**By ZeroUnderOne** — included with the manager with their permission.

When LET IT DIE went offline, some gear was made weaker. ZeroUnderOne put these
values back to what they were before, as part of Tengoku Enjoyer. This mod is
those values alone, for players who want them without the rest of it.

Tengoku Enjoyer already does this, so with it ticked this mod is not needed;
the manager says so if both are ticked.

| What                                      | Value                   | Offline | With this mod |
|-------------------------------------------|-------------------------|---------|---------------|
| Hell Ride (Motor Psycho's Rage move)      | Rage gauge it takes     | 2       | 1             |
| Hell Ride                                 | Attack                  | 600     | 1000          |
| Strike Bomb (Bowling Stomper's Rage)      | Rage gauge it takes     | 3       | 1             |
| M2G-87, third fire attack                 | Damage scale            | 100     | 215           |
| M2G-87, third fire attack (FF)            | Damage scale            | 100     | 200           |
| Red Napalm, knife                         | Ammo used per shot      | 6       | 3             |
| Red Napalm, knife                         | Durability per shot     | 18      | 9             |
| Armor Breaking Flail S (the stronger one) | Attack growth per level | 1.01    | 1.03          |

For research costs from the online game too, tick **Online Research Costs**.

Tick it and click **Save Mod List**. Unticking it puts the offline values back.
