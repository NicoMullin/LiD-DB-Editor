Put your replacement game files here.

Each file in this folder is copied to the matching path under the game's
BrgGame/CookedPCConsole folder, keeping its name. A subfolder here maps to the
same subfolder there.

For LET IT DIE that means whole .upk packages - character/equipment models,
UI icons, and so on. The manager does not open or understand the .upk format;
it copies the file, checks its hash, and swaps it into place.

This placeholder file is only here so the example has something to copy. Delete
it once you add real assets.
